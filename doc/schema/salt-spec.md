# 食盐专营模块口径（定死）

本文件是各模块判断口径的唯一书面的来源。口径三处同源：本文件、`doc/schema/salt.sql` 注释、各 ServiceImpl 类头注释——改一处必须同步另两处，不许只改一处。

## 1. 跨省经营备案单（t_salt_record_flow）

### 1.1 名录准还是单子准（取舍定死）

- **准入门槛以总名录为准**：立案递单、每一档推进的当下，企业必须在册（`t_salt_ent`：未删除、未摘牌）。摘牌企业递不进新单；名录里已摘牌的企业，其在办单不能再往前推进，只能收口止住。
- **单的环节与结果以单子为准**：单子一旦落定，它的 stage、流转段、封卷/收口结果只由单子自己的流转产生。名录后续变动（改名、改类、摘牌）**不反向级联改单**——动一下总名录，底下挂的记录不跟着抖。
- 一句话：受理/挪步时核名录（该核的两头都核），核完落单后各走各的。

### 1.2 一企一活单与幂等

- 在办(1)/止住(3)占用 `active_key`（生成列）+ `uk_active_ent`：一企同时只有一张活单。
- 重复递单（含并发并递）：不新建、不另起段，幂等回那张在办单。
- 推进/回退：乐观守卫（id + 旧 stage + 旧 status），并发只有一个落得下去；同一步第二遍空递不产生新段。

### 1.3 状态机

- stage：0递单受理 1材料核验 2生效确认 3缴回封卷。系统按已过档次数出来，一次只挪一档；表单递来的 req_stage 仅作来意，入库/回读都不看它。
- status：0未起 1在办 2已封卷落档 3收口止住。**落档与止住都封口：改不动/删不掉/挪不了。**
- 各档守卫（一步没走完不许跳到下一格）：
  - 1→2：核验笔填全 `check_required` 笔；填全一刻自动起公示钟（`publicity_start`）。
  - 2→3：公示够钟（`publicity_done_hours` 与判定同一次算出，不落二手数据）。
  - 3→封卷：旧证缴回回执已落（`cert_returned=1`）；封卷落 status=2，段记 stage_no=4。
- 回退只退一档（不回起点）；回退打断公示钟即清零（`publicity_start`/`publicity_done_hours` 清空）。
- 收口：`close_type` N不必备案 S就地止住 → status=3；落档封存不留收口说法。

### 1.4 流转段（t_salt_record_note）

- 每趟每进/退一档落一段；退档后重走另起一趟（`walk_no` 累加），旧段沉底保留不删。
- `seq` 本单内连续递增；`event_ms` 毫秒，同秒两笔各记各的。
- 改内容：同档第二遍不另起一行，改当前段留下的话（`said`），段上看得出改过的时刻与经手人。
- 倒推复核（audit）：段流是唯一来源，从段流推回 stage/status 与单上对账；段次断档、跳档、趟次错乱、封口不一致都列出来。

### 1.5 删除与留档

- 已封卷/已止住的单禁止删除（留档）；未封口的单物理删除并连带核验笔、流转段，释放一企一活单键。
- 台账只看 `del_flag=0`（封卷单仍在台账留档可见）。

## 2. 延续换证核签单（t_salt_renew_bill）

- 复核链三处判断同源：`requiredSigns`（`need_count` 优先，缺省按 `sign_mode` 一名即可/两名须同判）与 `isTerminal` 只有一处，approve/reject/rollback 不许各算各的。
- 本档落印算齐才进档；省核准档算齐即办结；否决落已挪回（不能不落）；退回退一档、本档印数清零、情形回在核；已办结/已挪回都拦截。

## 3. 抽检结果报送核收行（t_salt_spot_row）

- 批次号以入参为准，入参空取首行；两头都空没法归批，整批不入。
- 空批次返回 0；超 500 行返回 -1 且整批不入库；同一批次重复提交（含并发并递）不重复入库返回 0（先查重，`uk_batch_row` 兜底，并发撞键整批回滚）。
- 逐行校验：合法的收下(1)、非法的记失败明细(2)，都保留原始行号；返回成功行数。
- `listErrors` 与写入侧同源：同一张表、同一个失败态、`del_flag=0`、按行号升序。

## 4. 年检到期催办单（t_salt_year_task）

- 可处理 ⟺ 正常未删 + 待派(0) + 进入开口窗口 `[due_at − 提前量, due_at]`；提前量取 `amount`（最可提前几日开口），空按 2 天，夹在 [2,5] 天。
- 过了止点还待派的不自动派，归人工（分不出）。
- `runOnce` 复用 `listDue`（同源，只有一处算）；逐条待派→已派出，乐观守卫防并发重复派；单条失败跳过继续；空批返回 0。

## 5. 企业品种挂接簿页（t_salt_link_page）

- 列表：尊重调用方递来的条件，只统一补 `del_flag=0`，分页由调用方统一处理（服务内不再自起分页、不自加状态过滤）。
- 进展 0待挂 1已挂讫 2压页（冻住）：一次只挪一态；空状态按 0 兼容（存量）；推进落定生成核验串（`CHK-单号-目标态-毫秒`）写入 `content`；退回只退一态、不清核验串；压页后改不动/删不掉/挪不了。
- 挂接企业以总名录为准：按 `site_id` 回查在册企业落 `site_no`；`bill_no` 在正常单内唯一。

## 6. 碘含量分档判定线（t_salt_iod_line）

- 可用性唯一来源 `availableAt`：正常未删 + 在场(0) + `eff_start<=at<eff_end`（让位之日不含，空端不限）。
- 列表、角标计数、旁路复用（usable）、单规则/多规则求值全走同一谓词与同一排序（优先级降序、ruleCode 降序）。
- 分档：等于上限取高一档（严格小于才落低档）；输入越界（<0 或 >100）返回 0。
